
# My Notes App

A simple and responsive Notes Application built using React.

## Features
- Create new notes
- Edit existing notes
- Delete notes
- Search and reset note 
- Change page with 
  per page 10 note
- flexible acces of each pages
- Add colors to notes
- Save notes with date and time

## Technologies Used
- React
- JavaScript
- CSS
- Tailwind CSS

## Installation

```bash
npm install
npm run dev
```
